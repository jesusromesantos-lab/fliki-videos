# Fliki Videos

Este repositorio recopila los vídeos generados con [Fliki](https://fliki.ai) para el canal, junto con los materiales de apoyo del proyecto.

## Contenido

Los vídeos se organizan por tema. Ejemplos actuales:

- La maldición de Tutankamón (Parte 1 y 2)
- Las Líneas de Nazca
- El mito de la maldición de Tutankamón

## Nota sobre los archivos de vídeo

Los archivos `.mp4` no se versionan en este repositorio (ver `.gitignore`) debido a su tamaño. Este repo sirve como espacio de trabajo y documentación del proyecto.
